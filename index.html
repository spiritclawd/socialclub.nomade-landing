Qué es

Corre simple. Come real. Vuelve mejor.

Nomade. Social Run Club. es para quienes quieren moverse con gente, descubrir rutas y convertir el running en un ritual cercano. Entrenos simples, comida real, energía buena. Cero elitismo.

Filosofía

Entrenos simples. Comida real.

Correr para sentirte mejor, no para demostrar nada. Salidas accesibles, hábitos sostenibles y planes alrededor de comida real: fruta, café, tostadas, aguacate, conversación.

01

Movimiento real

Costa, ciudad, playa o paseo. La ruta importa menos que aparecer y moverte.

02

Entrenos simples

Ritmos humanos, sesiones claras y cero complicación. El objetivo es repetir.

03

Comida real

Después del run también hay club: café, tostadas, fruta, aguacate y comunidad.

Post-run ritual

Entrenos simples, comida real.

No va de sufrir más. Va de construir una rutina que puedas sostener: moverte, comer mejor, compartirlo y volver la semana siguiente.
